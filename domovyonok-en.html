Context

Tasks

The client needed to improve the product functionality and develop new features and sections.

Business goal: develop and improve the digital product by expanding functionality, optimizing existing flows and improving the user experience.

Task 1

Problem

Conversion to app installs was low. When choosing an order time, users encountered higher-priced slots without a clear explanation, which reduced transparency and trust. In addition, payment via the Faster Payments System was not obvious, making the process harder for users who preferred this payment method.

Solution

At the final checkout step, we added a banner presenting the benefits of the app with a quick-payment button via the Faster Payments System, reducing the barrier to entry and shortening the path to purchase.

In the cleaning-time selector, we introduced a “Show available times” checkbox (or similar wording) that hides higher-priced slots by default. This lets users decide whether they are willing to pay extra for urgency instead of encountering an unexpected price.

Result

After implementation, app installs, the share of payments via the Faster Payments System and the speed of choosing an order time increased.

Task 2

Problem

Cleaners did not use all app features because some functions were hidden behind unclear unlabeled icons. This reduced awareness of existing functionality and led to more support requests for tasks the app could already handle.

Solution

Hidden functions were brought to the surface so they were visible and understandable at a glance. We revised the screen layout, created clearer and more unambiguous icons, and prioritized information according to what a cleaner needs at each stage of the job.

Result

More independent use of app functions and fewer support requests.

Product

Three roles, one system

Domovyonok is a multi-role product: three different interfaces are tied to the same order. A change in one interface has to remain immediately understandable in the other two.

01

Client

Ordering app

Chooses the cleaning type, date and time, and tracks the cleaner on the map.

02

Cleaner

Worker app

Views the schedule, accepts jobs and marks cleaning stages.

03

Operator

Admin panel

Monitors orders, assigns cleaners and tracks workload.

System

Design system

A dedicated system was needed because the product has three interfaces across different platforms. Without shared tokens, the client app, cleaner app and admin panel would quickly diverge visually. I built it on an 8-pixel grid with a limited state palette.

Adaptation

MyElfy website for Malaysia

Adapted Domovyonok’s visual language for an English-speaking audience: simplified the presentation of plans, added local payment methods and reworked the landing page for Malaysian users.

Interface

Client app

Three key client-account screens: order history, live cleaner tracking on the map and one-tap repeat ordering.
