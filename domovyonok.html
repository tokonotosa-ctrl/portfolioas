Задача 1

Проблема

Конверсия в установку приложения была низкой. На этапе выбора времени заказа пользователи сталкивались с слотами по повышенной цене без понятного объяснения причины — это создавало ощущение непрозрачности и снижало доверие. Кроме того, оплата через СБП была реализована неочевидно, что усложняло процесс для пользователей, которые предпочитают этот способ оплаты.

Решение

На финальном шаге оформления заказа добавили баннер, презентующий преимущества приложения, с кнопкой быстрой оплаты через СБП — это снизило порог входа и сократило путь к покупке.

В блоке выбора времени уборки ввели чекбокс «Показать доступное время» (или аналогичную формулировку), который по умолчанию скрывает слоты с повышенной ценой. Так пользователь сам решает, готов ли он доплатить за срочность, вместо того чтобы наталкиваться на неожиданную цену.

Результат

После внедрения изменений выросли: число установок приложения, доля оплат через СБП и скорость выбора времени заказа.

Задача 2

Проблема

Клинеры не пользовались всеми функциями приложения — часть возможностей была скрыта за неочевидными иконками без подписей. Это приводило к низкой осведомлённости о функционале и, как следствие, к росту обращений в службу поддержки по вопросам, которые приложение уже решало.

Решение

Скрытые функции вынесли на поверхность интерфейса, сделав их видимыми и понятными с первого взгляда. Пересмотрели компоновку экрана, разработали более читаемые и однозначные иконки, а расстановку акцентов выстроили по приоритетам, актуальным для клинера на конкретном этапе работы.

Результат

Рост самостоятельного использования функций приложения и снижение количества обращений в поддержку.

Продукт

Три роли — одна система

Домовёнок — мультиролевой продукт: три разных интерфейса завязаны на один и тот же заказ. Изменение в одном интерфейсе должно быть мгновенно понятно в двух других.

01

Клиент

Приложение заказа

Выбирает тип уборки, дату и время, отслеживает клинера на карте.

02

Клинер

Приложение исполнителя

Видит расписание, принимает заявки, отмечает этапы уборки.

03

Оператор

Админ-панель

Контролирует заказы, распределяет клинеров, следит за загрузкой.

Система

Дизайн-система

Отдельная система была нужна из-за трёх интерфейсов на разных платформах: без единых токенов клиент, клинер и админка быстро разъехались бы по стилю. Построил её на 8-пиксельной сетке с ограниченной палитрой состояний.

Адаптация

Сайт MyElfy для рынка Малайзии

Адаптировал визуальный язык Домовёнка под англоязычную аудиторию: упростил подачу тарифов, добавил локальные способы оплаты и переработал посадочную страницу под привычки малайзийских пользователей.

Интерфейс

Клиентская часть приложения

Три ключевых экрана личного кабинета клиента: история заказов, живой трекинг клинера на карте и повторный заказ в один тап.
